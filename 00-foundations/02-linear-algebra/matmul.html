3. How they depend on each other


  prompt length P ──► prefill: M = P ──► high FLOPs/byte ──► fast per token ──► time to first token
                                                                               │
                                       KV cache filled for all P tokens ◄─────┘
                                                   │
  answer length G ──► decode: M = 1 ───► ~1 FLOP/byte ──► each token re-reads 0.70 GB ──► G × ~3.9 ms

  query latency = prefill (grows slowly with P) + decode (grows directly with G)
